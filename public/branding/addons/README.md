# Add-on card art

Drop a PNG per add-on id (matches `CONFIG.addons[].id`):

- `opd_wallet.png`
- `annual_check.png`
- `ultrahuman_ring.png`
- `womens_care.png`
- `dental_vision.png`
- `parent_screen.png`

Recommended: transparent PNG, ~320×240, product/icon facing right (portal-style header).  
If a file is missing, the Focus Zone falls back to the pixel mini-icon.
